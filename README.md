# SUNEXA — Ideas to Impact

SUNEXA is a static, responsive digital studio website reproduced from the supplied single-page design. It presents web development, software development, maintenance, hosting, portfolio work, pricing, process information, FAQs, and a project enquiry form.

## Run locally

```bash
npm start
```

The preview server listens on port `3000` by default and serves the single-page site at `/`.

## Portfolio previews

Each **View Build** control opens a responsive live preview for the corresponding project and provides an **Open Full Site** link to the unchanged external portfolio URL.

## Project files

- `index.html` — SUNEXA single-page website and client-side interactions
- `server.js` — minimal static preview server
- `manus-routes.json` — managed route manifest
- `app.config.ts` — project metadata
- `plan.md` — implementation and design notes
- `TODO.md` — delivered outcomes
