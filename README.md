# NEXAROQ — Ideas to Impact

## Run locally

This package contains the complete compiled website in `index.html` and `assets/`. Because the site uses React ES modules, start a local server instead of double-clicking the HTML file:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

For GitHub Pages, upload `index.html` and the `assets/` folder to the repository root.
